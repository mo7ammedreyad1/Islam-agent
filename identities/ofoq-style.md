# هوية "أفق الليلية" (Ofoq Night) — سينمائية، خلفية اختيارية بحركة Ken Burns

## 1. نظرة عامة
طابع سينمائي هادئ: خلفية إما صورة حقيقية بحركة تكبير بطيئة (Ken Burns) أو
تدرج رمادي فاتح احتياطي، وفوقها فينييت داكنة (تعتيم تدريجي من المنتصف
للأطراف) بتخلي أي نص أبيض فوقها واضح مهما كانت الخلفية. هيدر ثابت باسم السورة
والقارئ أعلى الشاشة، والآية نفسها في المنتصف بحركة **كتلة واحدة** (مش كلمة
كلمة زي `Quran.md`/`brown-style.md`) fade + تكبير + إزاحة خفيفة لأعلى. دقة
أصغر من باقي الهويات (720×1280)، بس نفس نسبة 9:16. مفيش بطاقة تفسير — تلاوة
minimal بس. حالة الاستخدام: تلاوة قصيرة/سورة صغيرة، طابع سينمائي هادئ بدل
الرَّق الكلاسيكي.

## 2. الهندسة والأبعاد
- الكانفاس: 720×1280 بكسل (نسبة 9:16)، 60 fps — أصغر من باقي الهويات.
- ترتيب الطبقات من الخلف للقدام:
  1. خلفية احتياطية (تدرج رمادي فاتح، تظهر دايمًا كطبقة أولى).
  2. خلفية صورة اختيارية بحركة Ken Burns (لو موجودة، بتتغطى فوق الاحتياطية).
  3. فينييت داكنة (فوق أي خلفية، صورة كانت أو تدرج).
  4. هيدر اسم السورة والقارئ (أعلى الشاشة).
  5. نص الآية الحالية (منتصف الشاشة الفعلي).
- الهيدر: اسم السورة عند `y = 120`، اسم القارئ تحته عند `y = 180`، خط فاصل
  رفيع عند `y = 220` من `مركز − 80` لـ `مركز + 80` (سُمكه `2px`) — الثلاثة
  متمركزين أفقيًا.
- نص الآية: يتمركز رأسيًا عند **نص ارتفاع الكانفاس بالظبط** (`y = 640` على
  كانفاس 1280)، بعرض أقصى للسطر `580px`، تباعد أسطر `حجم الخط × 1.5`، فراغ
  أفقي `14px` بين الكلمات.

## 3. لوحة الألوان
| الاسم | القيمة | الاستخدام |
|---|---|---|
| `bgFallbackTop` | `#FFFFFF` | أعلى تدرج الخلفية الاحتياطية |
| `bgFallbackBottom` | `#E5E5E5` | أسفل تدرج الخلفية الاحتياطية |
| `vignetteInner` | `rgba(0, 0, 0, 0.20)` | مركز الفينييت (تعتيم خفيف) |
| `vignetteOuter` | `rgba(0, 0, 0, 0.75)` | أطراف الفينييت (تعتيم قوي) |
| `textPrimary` | `#FFFFFF` | اسم السورة في الهيدر، نص الآية |
| `textMuted` | `rgba(255, 255, 255, 0.85)` | اسم القارئ في الهيدر |
| `dividerLine` | `rgba(255, 255, 255, 0.3)` | الخط الفاصل تحت الهيدر |
| `shadowHeader` | `rgba(0, 0, 0, 0.65)` | ظل خلف نصوص الهيدر (ضبابية 10px، إزاحة رأسية 3px) |
| `shadowVerse` | `rgba(0, 0, 0, 0.8)` | ظل خلف نص الآية (ضبابية 15px، إزاحة رأسية 4px) |

**واجهة التحكم/المعاينة** (خارج الفيديو نفسه — الأزرار والـ HUD) فاتحة/بيضاء
زجاجية، نفس الديفولت الثابت في الطبقة التقنية، **مش داكنة** — الغمقان كله
خاص بمحتوى الكانفاس نفسه بس.

## 4. الطباعة
- **نص الآية**: خط `Amiri` (بدائل احتياطية بالترتيب: `Georgia` ثم
  `Times New Roman` ثم `serif`)، وزن `700`. الحجم `60px` عادةً، أو `52px` لو
  نص الآية أطول من 30 حرف. لون `textPrimary`. محاذاة وسط.
- **اسم السورة في الهيدر**: خط `Reem Kufi` (بديل `sans-serif`)، وزن `700`،
  حجم `48px`، لون `textPrimary`.
- **اسم القارئ في الهيدر**: خط `Reem Kufi`، وزن `500`، حجم `26px`، لون
  `textMuted`.

## 5. الحركة
- **ظهور الهيدر**: fade بس (بدون إزاحة)، من الشفافية `0` لـ `1`، مدة `1.5`
  ثانية من بداية الفيديو، منحنى `linear` (نسبة الوقت مباشرة، بدون تسريع/تباطؤ).
- **ظهور نص الآية — كوحدة واحدة، مش كلمة كلمة**: النص كله بيتحرك مع بعض:
  - **الدخول**: أول `0.6` ثانية من بداية المشهد — fade من `0` لـ `1`، مع
    تكبير (`scale`) من `0.96` لـ `1.0`، وإزاحة رأسية من `+20px` لـ `0`،
    بمنحنى `easeOutCubic`.
  - **الخروج**: آخر `0.5` ثانية من المشهد — نفس القيم بالعكس (fade لـ `0`،
    scale لـ `0.96`، إزاحة لـ `+20px`)، بنفس منحنى `easeOutCubic`.
  - بين الدخول والخروج، النص ثابت بشفافية كاملة وحجم طبيعي.
  - التكبير والإزاحة بيتمحوروا حول مركز الكانفاس.

## 6. الخلفية والتأثيرات
- **الخلفية الاحتياطية**: تدرج خطي رأسي من `bgFallbackTop` (أعلى) لـ
  `bgFallbackBottom` (أسفل)، بيتغطي بالكامل قبل أي طبقة تانية.
- **صورة الخلفية الاختيارية (Ken Burns)**: لو موجودة، بتتغطى فوق التدرج
  الاحتياطي بالكامل (تملأ الكانفاس بدون تشويه نسبتها، زي `background-size:
  cover`)، بحركة تكبير بطيئة مستمرة طول الفيديو: نسبة التكبير بتبدأ `1.05`
  وتوصل لـ `1.13` (يعني `1.05 + تقدّم الفيديو الكلي × 0.08`) في آخر فريم.
- **الفينييت**: تدرج شعاعي (radial) مركزه نص الكانفاس بالظبط، نصف قطره
  الداخلي (بداية التدرج) = ربع عرض الكانفاس، نصف قطره الخارجي (نهاية التدرج)
  = ارتفاع الكانفاس ÷ 1.5. اللون في المركز `vignetteInner`، وفي الأطراف
  `vignetteOuter`. بتترسم فوق أي خلفية (صورة أو تدرج) في كل فريم.

## 7. الأصول المطلوبة
- **الصوت**: موجود، إلزامي. نفس `everyayah.com` بنفس نمط `Quran.md` — آية
  بآية، متلزّقة في صوت واحد.
- **الصورة**: **اختيارية بالكامل** (مش إلزامية) — تفعيل حركة Ken Burns محتاج
  رابط صورة `https://` بيدعم CORS فعليًا (`crossOrigin="anonymous"`)؛ لو مفيش
  رابط، الخلفية الاحتياطية (التدرج الرمادي الفاتح) هي اللي بتظهر طول الفيديو
  ومفيش أي مشكلة. أي صورة تُختار لازم تتأكد إنها بتدعم CORS قبل الاستخدام
  (`curl -sI` والتحقق من header اسمه `access-control-allow-origin`)، وإلا
  الكانفاس هيتعتبر "tainted" ويفشل التصدير.
- **فيديو B-roll**: مش موجود (المشروع مبني على صورة ثابتة بحركة كاميرا، مش
  فيديو خلفية).

## 8. شكل بيانات المحتوى
نفس حقول `Quran.md` بالظبط (`SURAH_NUMBER`, `RECITER_ID`, `RECITER_DISPLAY_NAME`,
`SURAH_DISPLAY_NAME`, `OUTPUT_FILENAME`, `SURAH_VERSES` — كل عنصر فيه `text`
بس، من غير تفسير). مثال بقيم توضيحية:
```
[
  { text: 'قُلْ هُوَ اللَّهُ أَحَدٌ ۝' },
  { text: 'اللَّهُ الصَّمَدُ ۝' },
  { text: 'لَمْ يَلِدْ وَلَمْ يُولَدْ ۝' },
  { text: 'وَلَمْ يَكُن لَّهُ كُفُوًا أَحَدٌ ۝' }
]
```

## 9. ملاحظات معروفة
- **جلب نص الآيات**: نفس مصدر `Quran.md` بالظبط —
  `https://api.alquran.cloud/v1/surah/{surah}/editions/quran-uthmani`،
  `response.data['ayahs']` (List)، مش `data['editions'][i]['ayahs']`.
- **الحركة هنا "كتلة واحدة" مش كلمة كلمة**: بعكس `Quran.md`/`brown-style.md`
  اللي بيعملوا ظهور متتابع لكل كلمة لوحدها، هنا الآية كلها بتتحرك كوحدة واحدة.
  لو محتاج تحويل الهوية دي لظهور كلمة-كلمة بدل الكتلة الواحدة، ده تغيير في
  قسم "الحركة" فوق، مش تفصيلة بسيطة.
- **الغمقان السينمائي مصدره الفينييت بس، مش لون خلفية داكن مرسوم مباشرة** —
  الخلفية الاحتياطية نفسها فاتحة (`#FFFFFF → #E5E5E5`). لو غيّرت الفينييت أو
  شيلتها، الفيديو هيبقى فاتح بالكامل، مش داكن.
- **مركز نص الآية على نص الشاشة بالظبط (`y = 640`)** — بعكس `brown-style.md`
  اللي بيزيح المركز لفوق عشان يسيب مكان لبطاقة تفسير؛ هنا مفيش بطاقة تفسير
  فمفيش داعي للإزاحة.
